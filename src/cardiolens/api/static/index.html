Условия использования CardioVision

Перед началом работы прочитайте и подтвердите:
  • CardioVision — вспомогательный инструмент поддержки решений врача. Результат — это не медицинское заключение и не диагноз.
  • Система может ошибаться: пропустить находку или показать ложную. Каждый результат врач обязан проверить по исходной записи ЭКГ.
  • Решения о диагнозе, лечении и тактике принимает только врач. Ответственность за эти решения несёт врач и медицинская организация.
  • Нельзя принимать клинические решения только на основании результата CardioVision. При угрозе жизни действуйте по клиническим протоколам, не дожидаясь разбора.
  • Сервис предназначен для медицинских работников. Он не предназначен для самодиагностики пациентами.
  • Не загружайте данные, по которым можно установить личность пациента (ФИО, номер карты).

Фото из Telegram или WhatsApp сжато — читается только ориентировочно. Лучше оригинал из галереи.
Подробнее о съёмке
Подойдёт фото бумажной ЭКГ или экрана прибора (JPG, PNG, HEIC), PDF, а также файл записи (WFDB, EDF, CSV, DICOM, SCP). Снимайте прямо сверху, без бликов, чтобы лист занимал весь кадр. Лучше всего — оригинал из галереи: фото, пересланное через Telegram или WhatsApp, сжато и читается только ориентировочно. Несколько фото одной ЭКГ можно выбрать вместе.
Где посмотреть скорость и усиление?
Посмотрите на край ленты: аппарат печатает там скорость и усиление (например, «50 мм/сек, 20 мм/мВ»). Если они не 25 и 10 — выберите их здесь, иначе ЧСС и амплитуды будут неверны.
Фото вертикальное. Поверните его так, чтобы строки ЭКГ шли слева направо, — иначе его не прочитать.
