Правила (DECISIONS D100):
1. Пороги подбираются только на наборах разработки.
2. Отложенные наборы прогоняются только для проверки решения, по критерию, записанному в DECISIONS до прогона.
3. Решение, не прошедшее отложенную проверку, откатывается. Повторно подгонять его под отложенный набор нельзя.
