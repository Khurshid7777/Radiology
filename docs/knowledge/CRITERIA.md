## Нет в системе (по книгам), по пользе

АВ-блокада II (Мобиц I, II, 2:1); пошаговое «ЖТ или аберрация» (Бругада / Верекеи / aVR); задний OMI;
депрессия ST в ≥ 6 отведениях + подъём в aVR (ствол / многососудистое); Сгарбосса–Смит по одному отведению;
острейший T; де Винтер; ещё 3 типа перепутанных электродов (нейтральный, RA↔LL, LA↔LL); плохой прирост R и
доминирующий R в V1; подтип НЖТ по RP; синдром Фредерика (ФП с регулярным медленным ответом); детские нормы
по Rijnbeek (верх ЧСС 0–3 лет, SV6/RV6).
