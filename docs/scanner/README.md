# ECG Scanner (модуль Cardiolens)

Входной адаптер модальности «фото/скан» для CardioLens. Он превращает фото
бумажной ЭКГ с телефона или планшета в калиброванный сигнал (мВ, секунды) по
каждому отведению, с оценкой достоверности, и честно отказывает, если качество
низкое. Это не диагностика: модуль только оцифровывает.

> Инструмент поддержки принятия решений. Не заменяет врача. Не медицинское изделие.

## Главное

- CardioLens уже умеет оцифровывать страницу 3×4 + ритм и ленту 12×1 (D35–D72).
  Сканер строится поверх этого кода (SD-003), а не заново.
- Цель «≤ 10 мс» относится к ошибке, которую вносит оцифровка (SD-010).
- Фото, отправленное в Telegram как фото, сжимается примерно до 4 px/мм, а порог
  ТЗ 8 px/мм. Поэтому отправлять нужно файлом (SD-009).
- Базовая линия M1 (SD-022): текущий оцифровщик хорош на чистом скане (r 0.97,
  QT 3 мс), но на фото не проходит ни одного критерия ТЗ, не определяет
  50 мм/с и 20 мм/мВ и в 71 % плохих случаев отвечает «ok». Это и есть план M2–M3.
- Итог M2 (SD-030): на «фото чистой бумаги» выполнены 6 из 8 критериев ТЗ
  (RR 0, QRS 8,5, QT 3 мс, r 0,96, ошибка R 0,03 мВ, 0 % плохих без пометки).
  Не выполнены SNR (10 дБ при пороге 15) и время (14 с при лимите 10 с).
  50 мм/с и 20 мм/мВ теперь определяются; доля плохих без пометки по всему
  набору 71 % → 26 %.
- Итог M3 (SD-038): собственная сегментация, панели из реестра, векторизация
  (DP + D47, «гибрид»), проверка тождеств конечностных отведений, артефакты
  подтверждения. На «фото чистой бумаги» снова 6 из 8 критериев (RR 0,6, QRS
  5,2, QT 3,5 мс, r 0,95), SNR 10,9 дБ и время 11,9 с ещё не проходят. По всему
  набору r 0,95 (старый оцифровщик 0,39). Плохих без пометки 4 из 114: трассы
  точные, ошибку даёт измерение ударов CardioLens на краю окна отведения (M4).
- Итог M4 (SD-044):
  - API `/scans` (очередь, SQLite, зашифрованные оригиналы, ключи доступа, подтверждение врачом с
    журналом и обратной связью, передача в CardioLens), Telegram-бот, тексты RU/UZ;
  - фото в CardioLens никогда не идёт в автономный режим B и помечено в заключении (D92);
  - плохих без пометки 4 → 2 из 114;
  - CI, красный с M2 из-за совпадения имён тестов, исправлен (SD-043).
