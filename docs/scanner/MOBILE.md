# Мобильный клиент (Flutter) — M5

Код: `mobile/ecg_scanner`. Решения: SD-046…SD-048.

## Сборка и тесты

```bash
cd mobile/ecg_scanner
python3 tool/sync_i18n.py         # строки RU/UZ из configs/scanner/i18n
flutter pub get
flutter analyze && flutter test   # 38 тестов, включая паритет проверки кадра с Python
flutter run                       # на подключённом телефоне
flutter build apk --release       # нужен Android SDK
```

Живой тест против запущенного сервиса:

```bash
ECGSCAN_LIVE_URL=http://<сервер>:8000 ECGSCAN_LIVE_KEY=<ключ> ECGSCAN_LIVE_PHOTO=<фото ЭКГ> \
  flutter test test/live_server_test.dart
```

## Как пользоваться

0. При первом запуске задайте PIN-код (4–8 цифр). Вход — по PIN или по отпечатку / лицу;
   после сворачивания дольше 5 минут (настройка) приложение снова попросит PIN (SD-073).
1. В «Настройках» укажите адрес сервера и ключ (один из `ECGSCAN_API_KEYS`, см. [SERVICE.md](SERVICE.md)).
   Маскирование ФИО и ID включено по умолчанию.
2. «Снять ЭКГ»: наведите камеру на лист. Подсказки («приблизьтесь», «уберите блик», «держите ровнее»,
   «нужно больше света», «поместите весь лист в рамку») сменяются на «Хорошо, держите — снимаю…», и
   снимок делается сам. Кнопка ручного снимка есть всегда.
3. Если известны скорость и усиление, отметьте их чипами. При маскировании шапки это особенно нужно:
   напечатанные «25 mm/s 10 mm/mV» закрыты.
   На экране «Углы листа» поправьте углы (лупа под пальцем), при необходимости поверните на 90° и нажмите
   «Готово». Снимок при этом не меняется: углы и поворот уходят на сервер вместе с ним (SD-071, SD-072).
4. Проверьте полосу маскирования: она должна закрыть ФИО и ID, но не трассы. Нажмите «Отправить».
5. Без сети снимок ждёт в очереди и отправится сам. В «Истории» виден статус.
6. Откройте снимок: цветные линии должны лежать на трассах. Дальше одно из трёх:
   - «Принять»;
   - «Исправить и пересчитать» — после правки скорости или усиления;
   - «Переснять».

   После `ok` доступно «Заключение CardioLens».

## Реальные фото (нужны для завершения M5)

Положите 20–50 обезличенных снимков по аппаратам:

```
data/real/<аппарат>/device.yaml    # layout: 3x4+rhythm, speed_mm_s: 25, gain_mm_mv: 10
data/real/<аппарат>/<id>.jpg       # фото (id без ФИО)
data/real/<аппарат>/<id>.xml       # та же запись в цифре: GE MUSE XML, или .csv/.edf/.hea+.dat
```

Отчёт:

```bash
python -m ecgscan bench --real data/real --out reports/scanner/m5-real
```

`data/real/` в git не попадает.
