# Программа на ноутбуке: записи с аппарата — сразу в бот (SD-152)

Без флешки: врач снимает ЭКГ как обычно, родная программа аппарата сохраняет запись в папку, наша программа замечает новый
файл и отправляет его, а разбор приходит врачу в Telegram (вопрос о пациенте → заключение, PDF).

## Как это устроено

1. Аппарат подключён к ноутбуку, как велит производитель (USB, сеть, SD-карта), и работает со **своей** программой
   (например, Edan Smart ECG Viewer). Мы не вмешиваемся в связь аппарата с ней.
2. В родной программе включено сохранение (экспорт) каждой записи в папку — лучше в PDF, XML или DICOM.
3. Наша программа следит за этой папкой. Новый файл, который перестал расти, она один раз отправляет на сервер
   CardioVision с ключом врача. При пропаже интернета отправит позже. Уже лежащие в папке старые записи при первой настройке
   не отправляются.
4. Бот присылает врачу «Получена запись с аппарата» и ведёт обычный разбор.

## Настройка (один раз)

1. В личном чате с ботом отправьте `/agent`. Бот пришлёт **ключ** — длинную строку. Скопируйте её целиком.
2. На ноутбуке выполните (пока — через Python; установщик `.exe` будет следующим шагом):

   ```
   python -m ecgscan_agent setup --server https://cardio.vision-ai.uz --key <ключ из бота> --folder "C:\путь\к\папке\экспорта"
   python -m ecgscan_agent run
   ```

   `status` — сколько отправлено; `once` — один просмотр папки.
3. Отключить программу: `/agent off` в боте (ключ перестаёт действовать для этого чата).

## Что важно знать

- Ключ умеет только одно — класть записи в очередь вашего чата; прочитать им ничего нельзя. Не пересылайте его.
- Сервер принимает только PDF, XML, DICOM и снимки (JPEG, PNG, TIFF) — по содержимому файла, а не по имени. Разобрать сервер
  умеет пока не все форматы аппаратов: что не прочитается, бот назовёт; новые форматы добавляются по образцам.
- В журналах программы и сервера нет имён файлов (в них часто ФИО пациента) и содержимого записей.
- Настройки и память программы: `%APPDATA%\cardiovision-agent` (Windows) или `~/.config/cardiovision-agent`.
