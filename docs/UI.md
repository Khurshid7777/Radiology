# CardioVision — интерфейс (D210, ТЗ «модернизация интерфейса»)

Страница — один файл `src/cardiolens/api/static/index.html` (разметка, стили, скрипт), без сборки и внешних
библиотек. Аудит, решения владельца и отчёты фаз — `docs/ui/AUDIT.md`; снимки «до» — `docs/ui/baseline/`,
«после» — `docs/ui/final/` (+ по фазам `docs/ui/p1…p4/`).

## Компоненты (id в разметке не менялись — на них опираются скрипт и тесты)

| Компонент | Где | Поведение |
|---|---|---|
| Stepper | `#stepper`, `body[data-step]` | ≥ 1024 px — две колонки и индикатор; < 1024 px — шаг на экран, «Далее / Назад / К данным пациента»; View Transitions, где есть |
| UploadZone | `#drop`, `.tips` | 3 пиктограммы, короткое предупреждение о сжатых фото, «Подробнее о съёмке» |
| SpeedGain | `.seg4[data-for]` | сегменты пишут в скрытые `#speed`, `#gain` (D179) |
| PatientForm | `#card2` | возраст и пол обязательны; режим A/B — `#mode_a/#mode_b` (виден); «Дополнительно» — K⁺, Ca²⁺, CSV-поля (только при CSV); «Служебное» — демо, ключ, качество |
| AnalysisOverlay | `#scanbox`, `#progress` | полоса-сканер по миниатюре снимка; статус `aria-live` без выдуманных стадий; «дольше обычного» через 10 с; финальный проход ≤ 350 мс, пропускается касанием |
| ResultSummary | `#lay1` | баннер, критические, **все предупреждения**, ключевые значения, заключение RU/UZ, PDF, ссылка, «Переснять», «Новый пациент», трассы с предупреждением, дисклеймер |
| Laboratory | `#lay2` | измерения, симптомы, сравнение, находки, кривая, граф, второй язык, ход рассуждений; «шторка» `clip-path` 350 мс |
| MetricCard | `#keys .key` | значение = API; шкала только из `d.norms`; счёт ≤ 600 мс |
| EcgViewer | `#ecgv` | `waveform.json`; 25 мм/с, 10 мм/мВ; перекрестие; линейка (мышь, клавиатура); под воротами — картинка |
| CausalGraph | `#cgv` | из `causal_graph`; подсветка цепочки; «Показать списком» |

## Правила, которые нельзя ломать (ТЗ 6.3)

- Числа, единицы, тексты заключений — ровно как в ответе API; нормы — только из ответа (`norms`).
- Предупреждения и дисклеймер — в первом слое и в PDF.
- Нет выдуманного прогресса; анимация не задерживает результат > 400 мс; всё пропускается касанием.
- Анимируются только `transform`, `opacity`, `clip-path`, `stroke-dashoffset`; `prefers-reduced-motion` — без движения.
- В браузере — только язык, ключ клиники и номер + время анализа (без значений).
