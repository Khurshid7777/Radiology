# Запрос ЭКГ для клиники (CardioVision, 19.11.2026)

Страница для передачи: https://claude.ai/artifact/AZG5cyBgkJEJ7fwBor9kKf (личная, открыть другим — через «Поделиться»).

Зачем: по открытым базам ЭКГ дальше не продвинуть распознавание АВ-блокад, медленной ЖТ и ЖТ против аберрации —
нужны настоящие ЭКГ с заключением кардиолога (DECISIONS D293–D316).

## Обезличивание (обязательно)
- Без ФИО, даты рождения, номера карты / паспорта, адреса, телефона, названия отделения на снимке.
- Можно: возраст (лет), пол, заключение кардиолога, лекарства, влияющие на ритм (если известны).
- На бумаге — закрыть данные пациента до фото; в файле — экспортировать без полей пациента.

## Формат (по убыванию предпочтения)
1. Файл с аппарата: SCP-ECG, DICOM ECG, XML (GE MUSE, Philips), EDF / CSV с отсчётами.
2. PDF, выгруженный с аппарата (векторный, не скан).
3. Фото бумажной ЭКГ: весь лист, строго сверху, без бликов; видны сетка и калибровочный импульс; 25 мм/с, 10 мм/мВ.
Стандарт: 12 отведений, 10 с; если есть — длинная лента ритма (II или V1) 30–60 с. Холтер — фрагменты 1–5 мин вокруг
эпизода, файлом.

## Разметка
- К каждой ЭКГ — заключение кардиолога (диагноз ритма и проводимости).
- Для АВ-блокад (п. 1–4) — отметить зубцы P: на бумаге точкой ручкой над каждым P (в т. ч. в T и в QRS, если видно),
  в файле — список времён P (с) или отметка «P на месте» по ударам. Это главное, чего нет в открытых базах.
- Для широких тахикардий (п. 5–7) — итог: ЖТ или НЖТ с аберрацией, и чем подтверждено (ЭФИ, ответ на аденозин, сравнение с
  прежними ЭКГ).

## Как передать
- Именование файла: номер пункта и порядковый номер, например `01_AVB3_001`; заключение — тем же именем в .txt.
- Канал передачи — по согласованию с владельцем проекта (защищённый, не мессенджер с автосохранением в облако).

## Что получит клиника
Отчёт по каждому нарушению: сколько распознано верно, где программа ошибается, какие правки сделаны и как изменилась
точность. Данные клиники используются только для проверки и обучения, в открытый доступ не передаются.
