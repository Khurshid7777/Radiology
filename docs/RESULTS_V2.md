# Итоги плана V2: старт → сейчас

Сравнение находок с метками на одних и тех же записях:
- код на старте плана — коммит `997a988`;
- текущий код — после D119.

Сверка — общий сверщик `validation/statement_score.py` с таблицей кодов `configs/statement_map.yaml` (D102).
Чувствительность — с 95 % интервалом Уилсона.

**Чистота наборов.** PTB-XL fold 10 остаётся отложенным для всего, кроме вариантов P/PR (D111) и критерия ЛП (D116).
Georgia g6–g11 и CPSC-Extra уже использованы для отложенных проверок части решений (D99, D105–D107, D112, D113, D116).
Для итога плана это внешние наборы, а не «нетронутые»: каждое принятое решение проходило свою проверку по
критерию, записанному заранее (DECISIONS).

## Что план не закрыл

- **Трепетание, прочитанное как ФП.** Чувствительность ТП 0.32 (Georgia) и 0.39 (CPSC-Extra), как на старте.
  Спектр (D113) и ряд волн F (D118) отвергнуты. Отложенный набор Ningbo (548 ТП) подготовлен для модели ритма.
- **ГПЖ** — 0 найдено на всех наборах; **патологический Q** на Georgia — 0.01; **депрессия ST** — 0.13–0.25. Планом
  не затрагивались.
- **Фото ЭКГ** (D114–D115) — проверены только на синтетике: реальных фото нет (404). В таблицах ниже не отражены.
