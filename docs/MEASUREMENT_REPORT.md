# Отчёт о точности измерений (по образцу IEC 60601-2-25)

**Это приближение, а не соответствие стандарту.** IEC 60601-2-25 (2011) проверяет глобальные длительности на
базах CSE/CTS по пределам таблицы 201.105: среднее отклонение от эталона и его SD. CSE и CTS — платные и здесь
недоступны. Вместо них два открытых эталона:
- **LUDB** — 200 записей, границы P/QRS/T размечены кардиологами в каждом отведении;
- **GE Marquette 12SL** — глобальные измерения PTB-XL+; отложенный fold 10, 1 491 запись (D97, D100).

Пределы (смещение / SD, мс) взяты из вторичных источников о таблице 201.105 и до регистрационного использования
требуют сверки с текстом стандарта: P ±10/15, PR ±10/10, QRS ±6/10, QT ±25/30. Для ЧСС и осей предела нет —
описательно (оси: доля в ±15°).

Генерация: `python -m cardiolens.validation.measurement_report --ludb … --ptbxl … --ptbxl-list … --twelve-sl … --out …`.
Состояние кода — после D101 (D103 в DECISIONS).

## Чтение

- **ЧСС, QRS против 12SL, оси QRS** — уровень коммерческого эталона.
- **QT:** против 12SL на 18 мс короче, против кардиологов LUDB — на 4 мс. 12SL меряет QT длиннее, чем кардиологи;
  проходит по обоим эталонам.
- **QRS:** против 12SL без смещения, против LUDB +5 мс, SD 13 мс — за пределом по разбросу. Эталоны расходятся
  между собой: LUDB размечает каждое отведение, мы берём медиану.
- **PR:** смещения нет, но SD 15–21 мс при пределе 10 — разброс в отдельных записях.
- **Длительность P:** на 28 мс короче 12SL, SD 26 мс — главное слабое место. Объясняет низкую чувствительность к
  увеличению ЛП (11/164 на Georgia, D102): P-mitrale опирается на длительность P. Разбор — D104.
